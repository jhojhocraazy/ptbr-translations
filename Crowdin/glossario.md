# 📖 Glossário Terminológico — Crowdin Platform (pt-BR)

> **Vocabulário padronizado para os conceitos de tradução contínua, internacionalização (i18n) e localização (l10n).**

---

## 🛠️ Tecnologias e Conceitos de Tradução

| Termo em Inglês | Tradução Padronizada (pt-BR) | Explicação / Contexto |
| :--- | :--- | :--- |
| **Translation Memory (TM)** | **Memória de Tradução (MT)** | Banco de dados de frases traduzidas anteriormente |
| **Machine Translation (MT)** | **Tradução Automática (TA)** | Motores de tradução por IA (Google, DeepL, etc.) |
| **Pre-translation** | **Pré-tradução** | Aplicação automatizada de memórias ou IA antes do trabalho humano |
| **Proofreading / Proofreader** | **Revisão / Revisor** | Etapa final de aprovação e controle de qualidade |
| **In-Context Localization** | **Localização no Contexto** | Tradução diretamente sobre a interface visual do app |
| **Glossary** | **Glossário** | Tabela de termos e regras de nomenclatura |
| **Vendor** | **Fornecedor** | Agência ou empresa de tradução profissional |
| **Cost Estimate** | **Estimativa de Custo** | Orçamento prévio gerado pelo Crowdin com base nas contagens |
| **Savings Summary** | **Resumo de Economia** | Relatório de custos poupados pelo uso de memórias e IA |
| **Source String** | **String de Origem** | Texto no idioma original (geralmente inglês) |
| **Target Language** | **Idioma de Destino** | Idioma para o qual se está traduzindo (ex: pt-BR) |
| **Approval** | **Aprovação** | Chancelamento da tradução por um revisor oficial |
