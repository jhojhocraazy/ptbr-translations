# 📖 Glossário Terminológico — TizenTube (pt-BR)

> **Tabela de padronização conceitual para o ecossistema TizenTube e TizenTube Cobalt.**

---

## 🧭 Interface do Usuário & Navegação

| Termo em Inglês | Tradução Padronizada (pt-BR) | Contexto / Justificativa |
| :--- | :--- | :--- |
| **Back** | **Voltar** | Botão de retorno na navegação da TV |
| **Home** | **Início** | Aba principal da plataforma |
| **Subscriptions** | **Inscrições** | Padrão consagrado do YouTube |
| **Library** | **Biblioteca** | Coleção pessoal do usuário |
| **Shorts** | **Shorts** | Nome oficial mantido |
| **Queued Videos / Queue** | **Vídeos na Fila / Fila** | Lista de reprodução temporária |
| **Watch Later** | **Assistir mais tarde** | Lista nativa de vídeos salvos |
| **Screen Off** | **Desligar tela** | Função de economia de energia/reprodução em segundo plano |
